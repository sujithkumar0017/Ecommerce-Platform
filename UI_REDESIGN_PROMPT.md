# 🎨 Premium Ecommerce UI Redesign Prompt

## 📌 Objective

Transform the existing ecommerce application into a **premium, modern, world-class shopping experience** while preserving all existing functionality.

The redesign should focus entirely on the **user interface, user experience, responsiveness, consistency, and visual polish**.

> **Important:** Do **NOT** modify business logic, APIs, routing, authentication, database operations, or application workflows.

# 📐 Layout & Alignment (Highest Priority)

Maintain a strict design system.

## Grid

* Responsive 12-column layout
* Consistent content width
* Responsive breakpoints

## Spacing

Use an **8px spacing system**.

Examples:

* 8px
* 16px
* 24px
* 32px
* 40px
* 48px
* 64px
* 80px

Maintain consistent spacing everywhere.

## Alignment

Everything must align perfectly.

Ensure:

* Cards align evenly
* Buttons align consistently
* Icons align with text
* Product grids remain balanced
* Forms have equal widths
* Images maintain consistent aspect ratios
* Tables remain perfectly aligned
* Headers align with content
* Footer follows the same layout width

Nothing should feel misaligned.

Every pixel should feel intentional.
